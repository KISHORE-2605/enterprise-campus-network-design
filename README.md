# 🌐 CCNA Campus Network Design

## 📌 Overview

This project demonstrates the design and implementation of a campus network using Cisco Packet Tracer. It includes VLAN segmentation, trunking, and inter-VLAN routing to enable communication between multiple departments.

---

## 🎯 Objectives

* Create VLANs for different departments
* Configure trunk links between switches
* Implement inter-VLAN routing
* Assign IP addressing for each VLAN
* Test connectivity between networks

---

## 🧩 Departments (VLANs)

* VLAN 10 → CSE
* VLAN 20 → IT
* VLAN 30 → MECH
* VLAN 40 → ECE
* VLAN 50 → EEE
* VLAN 60 → LAB
